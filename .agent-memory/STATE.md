## Gotchas

- A running `featherwin.exe` locks the build output (LNK1104) and its in-memory bookmarks/Shields state can overwrite saved files on exit/save; close it before rebuilding or relying on manual edits to `%APPDATA%\featherWIN\bookmarks.txt` / `shields-exceptions.txt`.
- `src/main.cpp` was rebuilt after a broken rewrite; bookmark drag/drop and popup-close behavior still need hands-on Windows testing.
- WebView2 extension install is from unpacked folders only; Chrome Web Store install is not supported.
- WebView2 runtime telemetry/update behavior must be checked against SPEC `C-PRIV` before release. Ctrl+Tab may be captured by VM/host keyboard mapping. Window/tab process memory should be measured against Edge/Chrome baseline per DECISIONS (2026-11-04).
